# WM19：八候选模型训练淘汰赛

状态：**训练实现和完整性核验通过，物理可靠性门槛未通过，禁止据此解除实机执行门槛。**

这是八组模型训练配置的选优实验，与执行时比较八个动作候选不同。它不是完整 Hyperband：采用一个预登记的有限淘汰日程，未运行 Hyperband 的多个预算 bracket。

## 模型与训练方法

所有候选严格使用同一 WM17 最佳检查点初始化，沿用 WM18 模型结构与完整生产损失。训练动作编码器、事件头以及四个局部分支：`action_encoder`、`events`、`local_action_context`、`local_spatial`、`local_attention`、`local_projection`；其余参数冻结并逐项核验。

WM 推理只读取 `history_images`、`history_state`、`history_valid`、`actions`。典型历史为 −80/−40/0 ms 的真实同步帧，动作窗口为 8 个命令、未来 0.32 秒。私有 ID、速度、姿态、几何、分割及真值掩码只用于生成监督与审计，不进入推理。预测接触不等于任务违规；接触实体区域是未来接触实体在当前帧的可见轮廓，非未来接触点。学习到的 attention 未经过可靠可见性或未知检测校准。

13,407 条唯一训练样本来自原始场景 11,792、运动 440、实体 327、可见性 336、侧向配对 512。五来源分组验证数量分别为 3,460/120/141/168/256。同场景与同种子变体保持分组，不把重复曝光计为新唯一样本。

每轮 358 个批次：完整批 33+5+3+3+4=48，末批 11+5+3+3+4=26。每轮根据实际 shuffle 重建各行更新质量 `m_i=sum_visits 1/(358*actual_batch_size)`；29 标签事件 BCE 使用单位正权重并乘 `1/(13407*m_i)`。区域、抓取、运动、未来 RGB、object/entity 历史 flow 和成对排序损失保持原函数与系数；该采样修正不等于概率校准。AdamW 权重衰减 1e-4、梯度裁剪 1，排序系数 0.1、margin 0.5。

重计算在 M2 Max 执行，本机负责调度和监测。采用 RAM 缓存和并行候选进程。没有匹配的完整串行吞吐基准，因此不声称等比例加速或 GPU 满载。

## 八候选及选优规则

四个学习率 2.5e-5/5e-5/1e-4/2e-4 × 两个采样种子 2027500000/2027510000。候选自身每轮实际采样 seed 为登记 seed+epoch。

累计轮次 6/12/24/30，候选数 8→4→2→1，总预算 102 个候选轮次、36,516 次更新。淘汰比较相同预算下的**最新轮次**验证指标；最终赢家选用其自身历史验证最佳检查点。不是比较八个候选各自历史最优值后全局取最小。

五来源验证 key 均值用于选优：每来源 `20*critical_macro_FN + critical_macro_FP + normalized_motion_MSE + 0.1*event_Brier + 0.05*(objectflow_MAE+entityflow_MAE)`。原四来源关注五类关键接触 total/new，lateral 来源关注 finger total/new；缺失正类明确记录，不算可靠性通过。全程分类阈值固定 0.5，独立数据不参与选模或阈值调整。

赢家 c05，学习率 1e-4，采样 seed 2027500000。c05 训练总计 30 轮/10,740 次更新，选定第 17 轮/6,086 次更新检查点。它是登记日程的胜出者，不代表已经达到物理可靠性要求。

选定权重 SHA-256：`2e200d67147784dac965aad6a9477c2f1e7f0f6ef330419f523e0c825a318b59`。

## 已完成核验

- 17,672 个源缓存 hash；八个 initial 与冻结 WM17 参数严格相等。
- 全部 102 个候选轮次真实采样质量重建；16 个 best/latest 检查点、优化器元数据及剩余冻结参数核验。
- 验证 key、等预算淘汰顺序与赢家检查点一致。
- 新独立 504 个 public 缓存及 216 个唯一 private 锚点 hash 核验。只有冻结赢家与 WM17 在此批数据上评分，其他候选未按独立结果重新选择。
- 18 个缺历史干预与当前帧无效拒绝通过，仅为结构检查；不证明预测准确率或校准。

## 归档与复现边界

`snapshot/` 为 M2 Max 已核验代码的逐字节归档，包含模型依赖、生产训练、串行和并行控制、生成器及评分核验实现。保留原目录结构和原执行路径；**不是可直接在任意电脑运行的一键训练包**。

原数据 manifest、场景资源、权重、完整私有状态及环境未发布。运行前需在隔离仿真环境准备原依赖并另行登记计划与数据指纹；不得直接执行归档控制器去覆盖已有实验。现有源码中保留的历史版本说明和阶段字段以 `evidence/` 的 WM19 记录为准。

`evidence/` 提供登记配置摘要、leaderboard、赢家、验证摘要、分项评分与失败门槛，保留报告及源码 SHA-256。`verify_archive.py` 可用标准 Python 验证本地代码归档 hash、102/36516 预算与赢家对应关系，不运行模型或仿真。
