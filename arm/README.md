## 控制分工

STM32 负责六轴电机控制以及与 ESP32 的夹爪 CAN 通信。ESP32 执行夹爪控制，并提供 Wi-Fi/BLE 夹爪查询和指令接口；当前并未实现 ESP32 脱离电脑转发六轴指令或直接连接手柄的 HID 驱动。

本地 FinalIntegration 的 `host/alan_robot` 和独立 ROS 桥接包尚未上传到此次仓库版本。它们负责模型量程适配、参考确认、标定/使能及动作时效门控等工作，不能用仓库现存的旧 ROS 节点代替其集成验收。

## 仿真与 ROS 2 边界

`ROS2/src/arm_asset/` 的 MuJoCo 资源已与 [REV6 双相机仿真](../model/RL/README.md)同步。前置相机为 48°，腕部为 45.2°。

- 当前 `mujoco_sim` 仍提供六关节控制与反馈话题，尚未接入夹爪控制和双相机图像话题。
- `arm_asset/urdf/` 是旧六轴描述，为原控制和标定模块保留；不是当前 REV6 完整夹爪和相机 URDF。
- 部分既有节点和启动文件仍使用旧路径、资源与接口配置。当前更新只完成静态资源和单项模型契约检查，未执行 ROS 2 整链路验证。

先运行仓库根目录说明中的独立仿真；ROS 接入需要另行核对模型、坐标、消息及执行网关。

## 硬件与验证状态

新固件未烧录，未进行最终版实机运动或联合闭环验收。六轴参考位、方向、传动比、限位及相机校准仍需独立验证。真实夹爪行程 0–74.63 mm，仿真为 0–80 mm，不能直接等同。

`STM32/` 下的 PCB 工程及原理图是保留的历史资料，本次没有核对其与 FinalIntegration 接线的一致性。最新软件检查结果见 [联合验证记录](firmware_tools/verification.md)。
